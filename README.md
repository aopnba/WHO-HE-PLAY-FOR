# WHO HE PLAY FOR?

Guess each NBA player’s current team from an archived headshot.

Play: https://aopnba.github.io/WHO-HE-PLAY-FOR/

Each round has 10 random players. Choose a team, submit your answer, and review your score. Player names can be hidden.

Static HTML, CSS and JavaScript; no backend or installation required. To run locally, serve this folder with a local HTTP server.
